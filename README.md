# Simple Todo App

This is a minimalist to-do application that runs entirely in the browser. It uses HTML, CSS, and JavaScript to provide a seamless user experience without needing a backend. All data is stored locally in your browser's local storage, ensuring your to-do items are saved even after you close the tab.

## Features

- **Add Todos**: Quickly add new tasks to your list.
- **Edit Todos**: Click the "Edit" button to modify an existing task.
- **Local Storage**: Your to-do list is saved in your browser's local storage, so your tasks will be there when you return.

## How to Use

1. **Add a Todo**: Type a new task in the input field and click the "Add" button.
2. **Edit a Todo**: Click the "Edit" button next to a task, and the input field will switch to "Update" mode, allowing you to make changes.
3. **Save Changes**: Click the "Update" button to save your edits.

This project is a simple demonstration of how to build a functional web application using only frontend technologies. It's a great starting point for anyone looking to learn the basics of web development.
